# Breeeeeath 🐑

Mini app de respiración guiada con una oveja dibujada a mano. Sin frameworks, sin dependencias — solo HTML, CSS y JavaScript puro.

## Funcionalidades

- Ciclo de respiración guiada: inhalar → sostener → exhalar
- Ilustración hand-drawn animada
- Contador de ciclos completados
- Sin dependencias externas — funciona offline

## Por qué este proyecto

Fue un experimento deliberado: ¿cuánto se puede lograr en diseño y UX sin ninguna librería? La ilustración de la oveja es el centro de la experiencia — el código existe para que ella funcione.
